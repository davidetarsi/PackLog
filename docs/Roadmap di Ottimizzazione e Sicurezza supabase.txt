Roadmap di Ottimizzazione e Sicurezza
Fase 1: Hardening delle Dashboard (Azione Manuale tua)
Questi passaggi servono a proteggere le chiavi pubbliche estratte dal binario dell'app. Cursor non può farli per te.

Supabase CORS: Accedi a Supabase -> Settings -> API. Cerca la sezione "CORS" e rimuovi l'asterisco * (che permette a chiunque di chiamare le tue API). Inserisci il Bundle ID della tua app iOS e il Package Name di Android (es. com.tuonome.packlog).

Sentry Rate Limiting: Vai nel pannello di Sentry -> Settings -> Projects -> [Tuo Progetto] -> Inbound Filters. Attiva i filtri per bloccare errori noti o spam. Poi vai su "Client Keys (DSN)" e imposta un limite di eventi per IP se disponibile nel tuo piano.

Amplitude Spam Filter: In Amplitude, vai su Settings -> Projects -> [Tuo Progetto]. Attiva i filtri anti-spam per ignorare flussi di traffico anomali provenienti dallo stesso IP.

Fase 2: Ottimizzazione del Boot (Azione di Cursor)

Modifica del file bootstrap.dart per parallelizzare le inizializzazioni I/O bound tramite Future.wait.

Questo abbatterà drasticamente i tempi di caricamento (App Startup Time) percepiti dall'utente.

Fase 3: Monitoring Realistico (Azione di Cursor)

Aggiornamento della configurazione di Sentry nel bootstrap.dart.

Impostazione del tracesSampleRate al 100% (1.0) anche in produzione, per non perdere neanche un trace durante le fasi critiche del lancio.
