Roadmap: Migrazione OpenAI su Supabase Edge Functions
Fase 1: Setup dell'ambiente locale Supabase (Azione Manuale tua)
Per scrivere Edge Functions, devi usare la CLI di Supabase sul tuo computer.

Installa la Supabase CLI (brew install supabase/tap/supabase su Mac, o tramite npm/scoop).

Nel terminale, vai nella cartella del tuo progetto Flutter e lancia: supabase init. Questo creerà una cartella supabase/ nel tuo progetto.

Collega il tuo progetto locale a quello cloud: supabase link --project-ref TUO_PROJECT_ID (lo trovi nelle impostazioni di Supabase).

Fase 2: Creazione della Edge Function (Azione di Cursor)

Creeremo una funzione chiamata analyze-clothing.

Cursor scriverà il codice TypeScript (Deno) che riceve l'immagine in Base64 dall'app Flutter, recupera la chiave OPENAI_API_KEY dalle variabili segrete di Supabase, chiama GPT-4o Vision e restituisce il JSON.

Fase 3: Sicurezza Server-Side (Azione Manuale tua)
Prima di fare il deploy della funzione, devi salvare la chiave OpenAI in cassaforte su Supabase.
Nel terminale lancia:
supabase secrets set OPENAI_API_KEY="sk-tua-chiave-segreta"
(In questo modo la chiave è blindata sul server e non c'è traccia sul tuo PC o su GitHub).

Fase 4: Deploy e Refactoring Flutter (Azione di Cursor)

Lancerai il comando supabase functions deploy analyze-clothing per caricare il codice sul cloud.

Cursor modificherà il tuo AiClothingAnalyzerService e la AiClothingSandboxScreen per rimuovere ogni riferimento alla chiave OpenAI lato client e usare Supabase.instance.client.functions.invoke().

TASK 1: Creazione della Edge Function (Backend)
Usa la Supabase CLI structure. Crea un file supabase/functions/analyze-clothing/index.ts.
Scrivi una Edge Function in Deno che:

Accetti richieste POST con un body JSON contenente {"image_base64": "..."}.

Gestisca i CORS headers per permettere le chiamate dall'app.

Legga la OPENAI_API_KEY usando Deno.env.get('OPENAI_API_KEY').

Effettui una chiamata REST a OpenAI API (gpt-4o-vision) passando l'immagine base64.

Estrapoli il JSON di risposta dalla AI e lo restituisca al client con status 200. Se ci sono errori, restituisca status 500 con il dettaglio dell'errore.
